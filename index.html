GitHub Auto-Publish Settings

When you load a new .pptx, the site will automatically push the file and rendered slide images to your GitHub repo — so the live site always stays current.

Create a token at github.com/settings/tokens → Fine-grained token → Repository: Contents = Read & Write.

Stored only in your browser's localStorage. Never sent anywhere except api.github.com.
